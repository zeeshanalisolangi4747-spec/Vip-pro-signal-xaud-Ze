VIP PRO SIGNAL XAU-D — Android starter project
================================================

Yeh Android project ka pehla starter version hai. Is mein Gold (XAU/USD) ka dashboard aur 15-minute timeframe ka layout hai.

IMPORTANT:
- Yeh abhi APK file nahi hai.
- Is version mein live market prices, real BUY/SELL signals, push notifications, RSI/EMA calculations ya data-source verification connected nahi hain.
- Screen jaan-boojh kar WAIT dikhati hai taake bina live data ke ghalat/fake signal na diya jaye.
- Trading mein profit ki guarantee nahi hoti.

APK banane ka tareeqa:
1. Is ZIP ko computer par extract karein.
2. Android Studio install/open karein.
3. "Open" se VIP_PRO_SIGNAL_XAU_D folder select karein.
4. Gradle sync mukammal hone dein (internet required).
5. Build > Build Bundle(s) / APK(s) > Build APK(s).
6. Android Studio APK ka path batayega.

Agla development step:
1. Legal/authorized XAU/USD live-data provider choose karna.
2. Doosre independent provider se timestamp aur price compare karna.
3. 15-minute candle data par RSI/EMA strategy implement karna.
4. Entry, SL, TP levels aur alerts add karna.
5. Historical backtest aur demo testing karna.

Free data sources can have rate limits, delayed prices, symbol differences, and API keys. Do not put private API keys directly into a public app.
